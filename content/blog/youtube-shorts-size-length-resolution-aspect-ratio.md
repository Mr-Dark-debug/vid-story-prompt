Use **1080 x 1920 pixels** for a conventional YouTube Short: 1080 pixels wide, 1920 pixels high, in a 9:16 vertical frame. Keep the finished video at three minutes or less. That preset gives you a clean Full HD portrait master, but it is not the whole platform rule.

YouTube's current organic classification is broader. For standard channels, an eligible video uploaded on or after 15 October 2024 is categorised as a Short when it has a **square or vertical aspect ratio** and runs for **up to three minutes**. A square file can therefore qualify even though it does not fill a tall phone screen. That distinction matters because many “exact specs” pages still mix up what YouTube accepts with what an editor should normally export.

## The short answer: requirement versus recommendation

Checked on 2026-07-31, these are the settings worth putting on an export card:

| Setting | YouTube's organic classification rule | Practical export recommendation |
| --- | --- | --- |
| Length | Up to 3 minutes for eligible current uploads | Use only the time the idea needs; do not stretch to the limit |
| Aspect ratio | Square or vertical | 9:16 portrait |
| Dimensions | No single pixel size stated on the Shorts upload page | 1080 x 1920 pixels |
| Container | Several video formats are accepted | MP4 |
| Video codec | Several supported paths exist | H.264, progressive scan |
| Audio | Must be part of a supported video file | AAC-LC, stereo, 48 kHz |
| Frame rate | No Shorts-only frame rate | Match the source frame rate |
| Black bars | Not part of classification | Do not bake them into a vertical master |

The left column answers “Will YouTube treat this as a Short?” The right column answers “What should I hand to YouTube for a predictable portrait result?” Do not turn recommendations into fake eligibility rules.

## What counts as a YouTube Short in 2026

[YouTube's three-minute Shorts guidance](https://support.google.com/youtube/answer/15424877?hl=en-GB) says that, for standard channels, square or vertical videos uploaded on or after 15 October 2024 are categorised as Shorts when they are no longer than three minutes. Videos uploaded before that date keep their previous long-form classification.

Official Artist Channels have a separate transition date. For those channels, the equivalent change applies to uploads on or after 8 December 2025. If you manage an artist channel through a label or distributor, use that rule rather than assuming the standard-channel date covers you.

The [desktop Shorts upload instructions](https://support.google.com/youtube/answer/12779649?hl=en-GB) reduce the current rule to two checks:

- the file is up to three minutes long;
- its aspect ratio is square or vertical.

YouTube does not say on that page that an organic Short must be exactly 1080 x 1920, exactly 9:16, or tagged `#Shorts`. Those choices can still be useful. They just solve presentation and discovery-copy questions, not the core file classification.

### The 60-second claim is now stale

Sixty seconds used to be the general Shorts ceiling, so the number persists in search results, old tutorials and editor presets. It is no longer the universal maximum for current organic uploads. Three minutes is the relevant ceiling under the current eligibility rules.

Some workflows still have their own shorter limits. An editor, scheduler, remix tool, music picker or ad placement may accept less than YouTube's native uploader. Treat that as a limit of the specific route, not proof that every Short must be under 60 seconds.

One current platform constraint does make the one-minute mark important: YouTube says a Short longer than one minute with an active Content ID claim of any kind will be blocked globally. If a 61-to-180-second edit uses music or other claimed material, clear the rights and check the claim status before publishing. “You can upload three minutes” is not the same as “every three-minute soundtrack is eligible.”

## Aspect ratio and pixel dimensions are different facts

An aspect ratio describes shape. Pixel dimensions describe the number of samples in that shape.

- **9:16** is a tall portrait shape.
- **1080 x 1920** is one Full HD-sized file with that shape.
- **720 x 1280** is a smaller file with the same 9:16 shape.
- **1080 x 1080** is a square 1:1 file.

Dimensions are normally written as **width x height**. This is where otherwise polished guides make a damaging error. `1920 x 1080` is a landscape frame; `1080 x 1920` is the portrait frame used for a full-screen-style Short.

### Is 9:16 required?

No. YouTube says square or vertical, not “9:16 only.” A 1:1 square upload can qualify. A taller-than-wide source can also meet the plain-language vertical requirement without being exactly 9:16.

Still, 9:16 is the sensible default for a Short designed around portrait viewing. It uses more of a tall mobile canvas and matches the common working format for other vertical-video platforms. [Google Ads' current video guidance](https://support.google.com/google-ads/answer/13982458?hl=en) lists 9:16 and 1080 x 1920 as its recommended vertical Full HD asset. That is helpful evidence for an export preset, but it is ad guidance—not the organic classification rule.

Use square deliberately when the composition benefits from equal sides or when aggressive portrait cropping would destroy the information. A screen recording with a wide interface, a two-person shot, or a diagram may retain more meaning inside a square canvas. The trade-off is unused space in a tall Shorts viewing surface.

## A dependable 1080 x 1920 export preset

If your editor exposes dozens of fields, use this as a conservative working preset:

| Export control | Setting |
| --- | --- |
| Canvas | 1080 x 1920 pixels |
| Pixel aspect | Square pixels |
| Container | MP4 |
| Video codec | H.264 High Profile |
| Scan | Progressive, not interlaced |
| Frame rate | Same as the source |
| Rate control | Variable bitrate |
| Audio codec | AAC-LC |
| Audio sample rate | 48 kHz |
| Channels | Stereo unless the source requires another supported layout |
| Colour for ordinary SDR work | BT.709 |

These choices follow [YouTube's recommended upload encoding settings](https://support.google.com/youtube/answer/1722171), not a special secret Shorts codec. YouTube accepts many file types, including MOV, MP4 and WebM, but MP4 with H.264 and AAC is widely supported by editing and review tools and is easy to inspect before upload.

Do not convert 24 fps footage to 30 fps just because a social preset says 30. Do not convert 30 fps to 60 fps to make the file seem more “premium.” YouTube advises uploading at the same frame rate used to record the content. Frame-rate conversion can duplicate or synthesize frames and introduce judder without restoring motion information that was never captured.

For current 1080p SDR uploads, YouTube's encoding page provides bitrate references for both standard and high frame rates. Use the current table in your export tool rather than treating bitrate as an eligibility gate. A clean source, sensible codec, correct frame rate and true portrait canvas matter more than chasing a huge file.

## Do not hide a landscape file inside a portrait-looking preview

A common failure begins with a 16:9 sequence. The editor places a portrait clip in the middle, shows vertical content in the preview, and leaves black areas inside the actual 1920 x 1080 render. The creator sees a tall subject and assumes the export is vertical. YouTube sees the complete landscape frame.

Inspect the rendered file's properties:

1. Confirm the frame width is 1080 and the frame height is 1920.
2. Open the exported file outside the editor.
3. Scrub the first, middle and last seconds for unintended bars or crop changes.
4. Check that rotation metadata has not produced a sideways preview in another player.
5. Upload privately or unlisted first when the format is new to your workflow.

[YouTube's upload guidance](https://support.google.com/youtube/answer/57407?hl=en) says its player adapts to vertical, square and horizontal video and advises creators not to add black bars to the sides of vertical uploads. If you need to preserve a landscape source inside a portrait Short, make the background an editorial choice: crop, recompose, or place the source over a designed portrait background. Do not let accidental padding define the file's real aspect ratio.

## Leave room for devices and the Shorts interface

A perfect 9:16 equation does not guarantee that every edge remains equally useful on every screen. Phones have different display shapes, rounded corners, notches and system areas. The Shorts player also places controls, channel information and captions over the video.

There is no honest universal pixel rectangle that protects every interface state and device. Use a safety habit instead:

- keep faces, product labels and diagram keys away from the outer edges;
- avoid placing essential words against the bottom or right-side control area;
- review burned-in captions at actual phone size, not only on a desktop preview;
- test at least one tall phone and one differently shaped screen when edge placement is tight;
- check the opening and closing frames, where animated text often enters or exits the safe area.

Community reports about 1080 x 1920 files appearing slightly clipped on one phone but not another are useful warnings, not a basis for inventing a universal crop percentage. Compose with breathing room and preview the rendered upload.

For caption timing, line length and placement decisions, use the separate workflow for [adding captions to YouTube Shorts automatically](/blog/add-captions-to-youtube-shorts-automatically). Format compliance will not rescue captions hidden behind controls or words that arrive late.

## Correct five claims that keep circulating

| Claim | What to use instead |
| --- | --- |
| “Every Short must be 60 seconds or less.” | Eligible current organic Shorts can run up to three minutes. Specific tools or rights conditions may impose shorter limits. |
| “A Short must be exactly 9:16.” | YouTube's organic rule says square or vertical. Use 9:16 for a conventional portrait composition. |
| “Vertical Full HD is 1920 x 1080.” | Width comes first: 1080 x 1920 is portrait; 1920 x 1080 is landscape. |
| “Add `#Shorts` and YouTube will recognise it.” | Classification depends on the eligible file's duration, aspect ratio and applicable upload date. A hashtag does not change the render. |
| “My scheduler's file limit is YouTube's limit.” | Third-party publishing tools can impose narrower formats, ratios or sizes than YouTube's native uploader. Check both sets of rules. |

This is why a page can rank and still give you a broken preset. Some current results state the new three-minute rule in one section and repeat the old 60-second requirement later. Others describe a vertical frame while printing landscape dimensions. Prefer dated primary help pages for rules, then apply editorial recommendations separately.

## Pre-upload check for editors and channel managers

Run this check on the final render, not on the timeline:

1. **Duration:** 3:00 or less for an eligible current Short.
2. **Shape:** square or vertical for classification; 9:16 for the standard portrait treatment.
3. **Dimensions:** 1080 x 1920 when using the recommended Full HD portrait master.
4. **Encoding:** MP4, H.264 progressive video, AAC-LC audio at 48 kHz.
5. **Frame rate:** matches the recorded source.
6. **Canvas:** no accidental 16:9 frame or baked-in black side bars.
7. **Composition:** faces, captions and labels survive phone-sized viewing and UI overlays.
8. **Rights:** every visual and sound element is authorised; check Content ID carefully on edits over one minute.
9. **Playback:** first, middle and last sections render correctly with synchronized audio.
10. **Upload test:** use private or unlisted visibility if you need to inspect processing before release.
