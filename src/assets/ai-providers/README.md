# AI provider and model-maker marks

Monochrome (`currentColor`) SVGs copied from [Lobe Icons](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg@1.95.1`, MIT licence). Only the files used by
`src/domain/ai/families.ts` are included; the `<title>`, inline size and style attributes were
removed so `ProviderLogo` controls size, colour and accessible naming.

`generic.svg` is a Vidrial-authored neutral fallback and is not from Lobe Icons.

The marks are trademarks of their owners. They appear only to identify which provider or model
maker a key, model or message belongs to; they do not imply endorsement or partnership.

To add a mark: copy the SVG here (file name = `logoKey`), reference it from the family registry, and
keep the file free of scripts, external references and fixed colours.
