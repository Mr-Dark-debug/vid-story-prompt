## Reproduction

```sh
bun install --frozen-lockfile
npm run typecheck
npm run lint
npm test
npm run build
npm run content:validate
npx playwright test e2e/motion-public.spec.ts e2e/motion-studio.spec.ts
```

Worker commands run from `services/video-worker`: `npm ci`, `npm run typecheck`, `npm run build`, `npm test`. Set `MOTION_TEST_CHROMIUM_PATH` to enable trusted native authored-fixture checks; this is not an execution mode for submitted HTML. On a verified Docker host, set `MOTION_DOCKER_TEST_IMAGE` and `MOTION_TEST_SECCOMP_PROFILE` to run the actual container test. PostgreSQL RLS/accounting checks run through `pwsh -File scripts/test-motion-db.ps1`. See the worker README and ADR 0002 for deployment controls.
